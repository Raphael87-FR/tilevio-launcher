# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through GitHub's
[private vulnerability reporting](https://github.com/Raphael87-FR/tilevio-launcher/security/advisories/new).

You can expect an acknowledgement within a few days. This is a personal
project maintained on a best-effort basis.

## Supported versions

Only the latest commit on `main` is supported.
