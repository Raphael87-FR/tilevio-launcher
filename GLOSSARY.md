# Tilevio Launcher

Tilevio Launcher is a minimalist TV home screen focused on opening installed apps. Its on-device display name is Tilevio.

## Language

**Launcher**:
The TV home screen from which the user opens apps.
_Avoid_: launcher app

**Default Home**:
The Launcher that the TV opens when the user presses the Home button. Tilevio offers to become the Default Home on first launch and from settings.
_Avoid_: home role, default launcher

**App**:
An app installed on the TV that the user can open from the Launcher.
_Avoid_: application

**Hidden App**:
An installed App whose Tile is intentionally omitted from the main screen. It remains available in settings to be shown again.

**Tile**:
The visual representation of an App in the Launcher, displaying its Android TV banner when available and its original icon otherwise.
_Avoid_: vignette

**Wallpaper**:
A static image or solid color chosen by the user and displayed behind the Tiles.
_Avoid_: animated background, fond d’écran
